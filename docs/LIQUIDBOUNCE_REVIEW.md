# LiquidLauncher and LiquidBounce source review

The uploaded `.lnk` is a shortcut to LiquidLauncher. The official launcher is Rust/Tauri with Svelte UI; the actual gameplay module/settings tree is in the Kotlin LiquidBounce client it installs. Both official repositories were downloaded for read-only source review outside the Levrn checkout.

Newer-branch source snapshot (Minecraft 26.3): [LiquidBounce 3758dceec37a](https://github.com/CCBlueX/LiquidBounce/tree/3758dceec37af780b4affeab67ba1245e22fe39f); [LiquidLauncher](https://github.com/CCBlueX/LiquidLauncher). The source trees were complete (`truncated: false`); counts are source-file/declaration counts, not promises of feature parity.

Inspected 1395 Kotlin source files by structural indexing, including **240 Module*.kt files** and **1860 directly named settings declarations**. Main configuration, KillAura, item cooldown, targeting, rotation, inventory coordination and Svelte configurable-settings code were read in detail. This index does not execute the code and does not enumerate every inherited or generated runtime option.

## Exact Minecraft 1.21.11 reference

The official **v0.37.0** release pins `minecraft = "1.21.11"` in `gradle/libs.versions.toml`. Its source commit is [`e77a6699123fad2e2d50748c0c7f764932bb0b13`](https://github.com/CCBlueX/LiquidBounce/tree/e77a6699123fad2e2d50748c0c7f764932bb0b13). Its index contains **232 Module*.kt files**, **1721 directly named settings declarations**, and 1272 Kotlin source files. This is the primary reference for Levrn. The earlier 240/1,860 counts describe the newer 26.3 branch, not this release.

## Actual settings architecture

- `config/types/Value.kt`: typed values, defaults, listeners, visibility conditions, persistence flags and reactive state.
- `config/types/group/ValueGroup.kt`: nested groups and factories for booleans, bounded numbers/ranges, enum choices and other setting types.
- `ModeValueGroup` and `ToggleableValueGroup`: branch-specific and enable/disable settings subtrees.
- `features/module/ModuleManager.kt`: the gameplay module registry.
- `src-theme/.../ConfigurableSetting.svelte`: recursive settings UI; module options are not a flat toggle list.
- KillAura splits click timing, interaction range, target tracking, rotation and aim-point selection into separate trees, with independent requirements, raycast, criticals and inventory-handling options. Auto Weapon coordination and shared combat pause state are explicit.

## Implications for Levrn

The 0.2 targeting fixes implement concepts independently: visible rotation before attacking, hitbox range, a weapon-aware cooldown, explicit target filters and state diagnostics. Levrn still has a much smaller settings model. **It does not yet implement the complete LiquidBounce module backend, nested mode tree, rotations system or server-specific behavior.** This review must not be presented as importing all 240 modules.

LiquidBounce/LiquidLauncher are GPL-3.0 projects. No GPL implementation code is copied into the current Levrn source. Direct incorporation would require compatible licensing and source distribution; charging for a client alone does not remove those requirements.
